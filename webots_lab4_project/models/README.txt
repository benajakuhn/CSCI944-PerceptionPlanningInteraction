VOSK MODEL FOLDER
=================

The speech model is a data dependency, not source code, so the approximately
40 MB model archive is not embedded in this project ZIP.

From the project folder, run:

    python download_vosk_model.py

The script downloads and extracts:

    models/vosk-model-small-en-us-0.15/

Official model list:
https://alphacephei.com/vosk/models
